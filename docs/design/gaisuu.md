# gaisuu.html の設計メモ
- 教材が四捨五入の答えを言うことはしない。▲の左右を色分けした帯の「幅」を見て子どもが判断する道具
- 画面の構成（上から）：`.quiz`（□ → 約 □ ＋ 候補ボタン ＋ 判定ボタン、カードの外）／`.board`（右上にツール、中に数直線）／画面下に出るテンキー・候補パネル
- SVG座標系 viewBox 0 0 1000 260。始点X=110 / 終点X=890 固定。1めもりは `SPAN_PX / state.divisions`
- `state.divisions` は 10（めもり11・ボックス2つ）か 20（めもり21・ボックス3つ）。20は11の**拡張**なので、めもりの見た目は全部同じにする（細い補助めもりを混ぜない）
- 数直線上の値は `<input>` ではなく `<button class="axis-box">`＋自前の画面テンキー。iPadでOSキーボードを出さないため。物理キーボード（0-9 / Backspace / Enter / Esc）も document の keydown で受ける
- 入力の実体は `state.text`（文字列）。`check()` が判定し、`validate()` が有効なときだけ `state.start/mid/end` を更新して `renderAll()` を呼ぶ。無効なあいだは**描画を変えず**ボックスを赤くするだけ。なおしかたはテンキー内のヒントに出す
- 入力ルール：一の位が0、となりあうボックスとの差が 10〜100000 の10のべき乗、3つのときは左右の差が等しい
- ハイライトは数直線の上半分（`BAND_TOP`〜`LINE_Y`）。▲がいる側のボックス同士で比較する（3つのときは中央で区切る）
- `renderAll()` はめもりと線、`renderMarker()` は▲・帯・吹き出しのみ。ドラッグ中は後者だけ呼ぶ
- 始点/終点/分割数が変わると marker と まるつけ結果 は null に戻す
- まるつけ：四捨五入の位は「となりあうボックスの差」から決める（`roundStep()`）
- 候補ボタン：もとの数から各位で `floor(num/step)*step` を作り、実際に入る組み合わせを一覧にする
