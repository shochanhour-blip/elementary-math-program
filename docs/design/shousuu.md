# shousuu.html の設計メモ
- ねらいは「10等分してもう1桁下を作る」を、拡大でつなげて見せること。0〜1 → 0.1 → 0.01 → 0.001 と降りていける
- 1本の数直線は `{ exp, off }`。1目盛りは `1/10^exp`、画面の左はしが `off` 目盛りめ。画面幅はいつも10目盛りぶん
  - **`off` は小数でよい**（なめらかにスクロールするため）。いっぽう**目盛りに振る数は必ず整数 `n`** なので、`0.1+0.2` のような誤差は出ない。ラベルは `n` を文字列にして小数点を差し込むだけ
  - 表示する目盛りは `ceil(off)` 〜 `floor(off+10)`。10等分していない段は `n % 10 === 0`（ひとつ上の位）だけ
  - `n % 10 === 0` の目盛りは太くする。「ひとつ上の位の目盛り」がそのまま太線になる
- 拡大＝選んだ区間 `n〜n+1` → `{ exp: exp+1, off: n*10 }`。整数の掛け算だけで子ができる
- ラベルは整数を文字列にして小数点を差し込むだけ（`fmt`）。書き方は2つ：
  - **等分前の線は末尾の0を落とす**（`fmtTrim`）。拡大した直後は親と同じ「0.3〜0.4」と出て、10等分すると「0.30…0.40」に変わる。桁が増えたことが見える
  - **0 や 1 のような整数は常に整数表記**（`fmtLabel`）。0〜1 を等分しても「0.0」「1.0」にはしない。0.90〜1 の並びでも右端は「1」
- ▲は `MARK_EXP=6` の整数1つで持ち、範囲に入っている線すべてに描く。**値のラベルは出さない**（目盛りを読ませるため）
- ▲は目盛りの `SNAP_PX`(13px) 以内で**吸着**する（`xToMark` → `nearestTick`）。10等分していない段では10ごとの目盛りにだけ吸着。
  吸着したことを枠や色で示すことはしない（見た目で目盛りに乗っているのが分かるため）
- 各段は横ドラッグで**なめらかにスクロール**する（`panTo`：`off` を連続で動かす）。◀ ▶ は1目盛りずつで、**切りのいい位置にそろえながら**動く（`panStep`）。範囲は 0〜`MAX_VALUE`(100)
  - 上半分は「タップ＝区間を選ぶ／横ドラッグ＝スクロール」。`endDrag` で `moved` を見て分ける
  - 子がスクロールして親の範囲から出たら、拡大のつながり（黄色）は描かない
- 選んだ区間は目盛りの値 `n` で覚える。スクロールしても同じ数の場所にとどまる（画面外に出たら解除）
- 選べるのは「となりあう目盛りの間＝1区間だけ」。2区間だと10の累乗から外れて桁の話が崩れる
- 等分していない線は拡大できない（等分 → えらぶ → 拡大 の順を強制する）
- 等分を解除したら、その目盛りから生えた拡大も消す（`toggleDivide` の `slice`）
- 段は gaisuu.html と同じく1枚のSVGに積む。`viewBox` の高さを段数ぶん伸ばす
- 画面に収めるのは **CSSだけ**：`svg { width:100%; height:auto; max-height:100% }` と、親を `flex:1 1 auto; min-height:0`。
  viewBox があるので歪まずに縮む。ookinakazu のような JS の `zoom` は要らない
- 上限は4段／`exp` 4まで（0.0001）。ラベルが長くなるので `labelFont()` で字を小さくする
- SVG内のボタン（10等分・✕・⊕）は gaisuu と同じく手動あたり判定。線の**上半分＝区間を選ぶ／下半分＝▲**で分けている
