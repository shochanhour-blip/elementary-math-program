# taikakusen.html の設計メモ

実装済み。

## 狙い
通常は「図形 → その対角線を調べる」という順で性質を学ぶところを、**対角線を先に決めてから辺を引く**という逆順で体験させる。対角線の長さ・交わる位置・交わる角度を子どもが決めると、その結果として図形の種類が決まる。

## 画面
- 単一SVG `viewBox 0 0 1000 640`
- メインフィールド x 0〜790（うっすら方眼を常時表示。判定には使わない）／棚 x 800〜1000
- 棚には長さ違いの棒が短い順に縦並び。**本数の制限なし**。1本の棒は1つの結合まで持てるので、2本1組の図形をいくつでも作れる
- 図形の名前は**各図形の中央**にSVGで描く（漢字＋下に小さくよみがな）。複数の図形があるため、カード外の1行では足りない
- カード右上にピクトグラム2つ：クリア（ゴミ箱）／図形の名前トグル

## 棒（対角線）
| 項目 | 値 |
|---|---|
| 太さ | 18 / 両端は丸 |
| 長さ | 240・300・360・420 の4種（点の間隔 40・50・60・70） |
| 色 | 全長さ共通。長さごとに色を変えると「同じ色＝同じ長さ」が答えになるため |
| 6分割の点 | 半径4の灰色の丸。**結合できるのは内側の5点だけ** |
| 頂点（両端） | 半径9の色付きの丸。結合後に大きくなる |

- 分割は長さに対する比率。長さが違う棒でも**点3は必ず中点**になり、「点3どうしで結合＝互いの中点で交わる」が点番号の比較だけで判定できる
- 端を結合対象から外すのは、2本が互いの内側で交わるときだけ4端点が凸四角形になり、その2本がちょうど対角線になるため。有効な結合は 5×5＝25通り

## 操作
| | 単独の棒 | 結合しているとき |
|---|---|---|
| 移動 | 棒の上をドラッグ | 結合部をドラッグ（図形ごと） |
| 回転 | 選択 → 回転ハンドル | 選択 → 回転ハンドル（**結合点が軸**、選んだ棒だけ回る） |
| 辺を引く | — | 頂点をドラッグ → 相手の頂点へ |
| 辺を消す | — | つないだ相手へもう一度引く |
| 結合の解除 | — | 結合点から引き離す |
| 片づける | 選択してフィールドの枠外へドラッグ | 同上 |

- 端のドラッグは**常に「辺を引く」**。端をつかむ回転は無い（回転は「選択 → ハンドル」の1種類のみ）
- 辺を引き始めると、つなげる相手の頂点2つだけが光る。同じ棒のもう一方の頂点（＝対角線そのもの）は光らない。完成形を点線で先に見せることはしない
- 片づけは画面の物理的な端ではなく**メインフィールドの枠外（棚の上を含む）**で成立させる。iPadの端スワイプに奪われないため

## 吸着としきい値
| | 値 | ふるまい |
|---|---|---|
| 結合スナップ | 点どうし24以内 | ゴーストで予告してから吸着 |
| 引き離し | 結合点から60以上 | 近づくほど結合点が薄くなり手応えを出す |
| 垂直吸着 | 相対角 90°±4° | 90°に吸着し、直角マークが出る |
| 平行の下限 | 相対角 15° | これ以上つぶせない（四角形が線になるのを防ぐ） |

## 判定
3条件すべてが離散値で、誤差計算が入らない。

| 条件 | 判定方法 |
|---|---|
| 互いの中点で交わる | 結合点の番号が両方とも3 |
| 長さが等しい | `len` が一致 |
| 垂直 | 90°吸着フラグ |

| 中点 | 等長 | 垂直 | 図形 |
|---|---|---|---|
| ○ | ○ | ○ | 正方形 |
| ○ | ○ | × | 長方形 |
| ○ | × | ○ | ひし形 |
| ○ | × | × | 平行四辺形 |
| — | — | — | 台形（結合点の番号が同じ、または合計が6のとき。むかいあう1組が平行になる） |
| — | — | — | （いっぱん）四角形（それ以外） |

名前は**辺が4本そろってから**、トグルONのときだけ表示する。

## 直角マーク
2本が90°に吸着したとき、交点にできる**4つの直角すべて**に薄い赤の直角マークを自動で出す。トグルは無い。吸着が外れれば消える。

対角線の「半分」に等長の印を付ける方式は、いったん実装したのち削除した。

## 辺の色分け
引いた辺は長さのグループごとに色を変える（誤差0.8以内を同じ長さとみなす）。
- 4本すべて同じ … きいろ `#efb810`
- 2本ずつ同じ … 短い組があお `#2f80ed`、長い組がきみどり `#8bc34a`
- 2本だけ同じ … その組だけ色を付け、残りは濃いグレー
- 全部ちがう … すべて濃いグレー

## 状態と描画
```js
state = {
  rods: [ {id, len, color, cx, cy, angle} ],  // 本数の制限なし
  joins: [ { a:{rod, pt}, b:{rod, pt} } ],    // 1本の棒は1つの結合まで
  sides: [ ["1:0","2:6"], ... ],              // 頂点idの組。図形ごとに最大4
  pick: null,        // 辺を引くとき最初にタップした頂点
  hover: null,       // 辺を伸ばして見せるためのポインタ位置
  showName: false
}
```
- 辺は座標ではなく**頂点idの組**で持つ。だから棒を回すと辺が追従する
- `joinOf(rodId)` / `partnerOf(rodId)` / `sidesOf(join)` で、ある棒や結合に属するものを引く
- 判定・色分け・名前はすべて**結合（＝図形）ごと**に計算する

## この教材の見せ場
平行四辺形を作ってから片方の棒を回して垂直に吸着させると、引いた辺がついてきてひし形に変わる。対角線を変えると図形が変わるという関係が、一続きの動きとして見える。
