# ookinakazu.html の設計メモ
- ねらいは「一十百千のならびが 万・億・兆でも くりかえす」ことを色で見せること。くらいの色は `exp % 4` だけで決まる（`.p0`〜`.p3`）。一・一万・一億・一兆が同じ赤、十・十万・十億・十兆が同じ黄……
- くらいは 10の何乗か（exp）で持つ。0=一、3=千、4=一万、8=一億、12=一兆。小数は扱わない
- `state.counts[exp]` はタイルの「数」だけ。タイルは区別しないので個別オブジェクトは持たない
- 表は1つの CSS grid。上から ①くらいの名まえ＋角の＋／－ ②万・億・兆の帯（`grid-column: span n`。一〜千だけのときは出さず、そのときは名まえの段が `.underline` で仕切る）③タイルの部屋 ④数のだん
  - 帯は名まえの**下**に置く。上から下に読んで「十」「万」＝十万とつながるようにするため
- 万・億・兆のまとまりは太線（`--group-line` 4px）で囲む。線はどの段でも**そのまとまりの左はしの列の `border-left`** に引く（`isGroupStart()`：`exp % 4 === 3` かつ先頭列でない）。右側に引くと段ごとに4pxずれて線が折れる
  - 帯の段だけは背景が濃いので線を白にしている（`.group-cell.group-start`）。表の外わくも同じ 4px `--group-line` にして、いちばん外のまとまりも囲まれて見えるようにした
- `renderAll()` は表ごと作り直す（くらいの範囲・表示モードが変わったとき）。タイルの増減は `renderTiles()` + `renderValues()` だけ。手書き canvas に触らせないための分割
- タイルの並び（`.stack`）は **grid**。`grid-auto-flow: column` ＋ `grid-template-rows: repeat(5, ...)` で「たて5こ→次の列」。幅は `--cols`（= ceil(n/5)）から calc で明示的に決め、ブラウザの intrinsic width に頼らない
  - `flex-flow: column wrap` で組んでいたときは、WebKit が折り返した列を幅に数えず、囲いの破線が左1列だけを囲む崩れが出た。Chromium では正しく出るので気づきにくい。幅を推測させない作りにしてある
- 10こごとに `.bundle`（破線の枠）で囲む。かたまりは**まるごと1つ**としてドラッグする。ばらのタイルは1こずつ
- 部屋の中は `justify-content: center` で中央ぞろえ。`flex-wrap: wrap` にして、横に入らないかたまりは下へ折り返す（行の高さを2倍にしたぶんを使う）
- 列幅 `--col` は「いちばん幅を取るかたまり1つ＋左右の余白」が必ず入る大きさを JS が計算して入れる（`syncColWidth()`）。中央ぞろえで中身が列からはみ出すのを防ぐため。折り返すので**合計ではなく最大**でよい
  - 以前は左に矢印ぶんの余白15pxを取りながら列の最小幅78pxがそれを見込んでおらず、囲いが右にはみ出していた
- タイルが増えて部屋の背が伸びることがあるので、`renderTiles()` からも `fitToScreen()` を呼ぶ。呼ばないと縦にはみ出す
- ドラッグの行き先は1つだけ：かたまり→ひとつ上のくらい（くりあがり）／タイル1こ→ひとつ下のくらい（くりさがり）。表の中の他の場所に落としても何も起きない
- **表の外で離すと捨てる**（`inTable()`）。ゴミばこボタンは置かない。捨てられる合図として、外にいるあいだドラッグ中のゴーストを薄くする（`#ghost.discard`）。かたまりは10こまとめて消える。パレットから持ったタイルは対象外
- くりあがりゾーン（kurainohyou にはある）は置かない。ユーザーの指示で、となりの位へ直接ドラッグする方式だけにしている
- ドラッグの当たり判定は `elementFromPoint` → `.cell[data-exp]`
- ドラッグ終了直後の click でタイルが増えないよう、`dragEndAt` から 300ms は **部屋のタップだけ** 無視する（`addTile(exp, fromCell)`）
- くらいの増減は kurainohyou.html と同じ「いちばん左の見出しの角の ＋／－」。1くらいずつ動かす（`state.topExp` を ±1）。上限は 12（一兆）
- kurainohyou と違い、－ はその部屋にタイルが残っているあいだ disabled。黙って消さない（`syncCornerBtns()` を `renderTiles()` から呼ぶ）
- タイルは表の下の「タイル」パネル（`.zone-palette` / `.tile-source`）から出す。kurainohyou のタイルパレットと同じ見た目・同じ置き方：72px・紫のリング・タイルに値（1 / 10 / … / 1000万 / 1兆）を書き、**自分のくらいの部屋へドラッグ**する（`kind: "source"`、`dropExpFor()` は同じ exp を返す）。ちがうくらいに落としても入らない
- 表が最大13列と横に長いので、パレットは kurainohyou の右ペインではなく表の下に置く。**表と同じ `.table-wrap`（同じ横スクロール）の中**に入れ、`grid-template-columns` に表と同じ値を渡して、くらいの部屋とタイルが縦にそろうようにしている
- ただし動かさずに離したとき（`moved` が false）はタップとみなして1こ置く。iPad で1こずつ足すのにドラッグを強いないため。部屋のタップでも増える
- パレットのタイルは減らないので `.dragging` を付けず、外で離しても何も起きない
- ドラッグの `setPointerCapture` は掴んだ要素自身に取らせ、pointermove/up もその要素で受ける（kurainohyou の `startDrag()` と同じ形）
- 表の中のタイルは28px・ラベルなし。13列 × 最大40こを並べるためで、ここは kurainohyou（44〜64px・値つき）と違う
- タイルの部屋と数のだんの高さは `--cell-h` / `--val-h`（どちらもタイル5こぶんの2倍相当）。画面に入らないときは `#board` 全体を `zoom` で縮めて必ず収める（`fitToScreen()`）
  - **縦だけでなく横も見る**。`k = min(1, 高さの比, 幅の比)`。表がほしい幅は「列数 × `--col` ＋ 外わく8px」を計算で出す（1fr で伸びるので、測っても『いま広がっている幅』しか分からない）
  - `.table-wrap` の `max-width` は JS がその必要幅まで広げる。わくが中身より狭いと、縮めても横スクロールが残ってしまう
  - `transform: scale()` は**だめ**。レイアウトの高さが変わらないので包み要素の中で内部スクロールが起き、`elementFromPoint` の座標がずれてドラッグが効かなくなる。`zoom` はレイアウトごと変わるので座標が合う
  - ゾーン外にいる `#ghost` だけは zoom がかからないので、`--k`（縮小率）を JS が渡して `transform: scale(var(--k))` で合わせる
- パレットは表と同じ grid なので**折り返しようがない**（必ず1行）。タイルは `width: min(72px, calc(100% - 10px))` ＋ `aspect-ratio: 1` で、列がせまいときだけ小さくなる
- 下のだんは2モード。`renderValues()` は**手書きの canvas がすでにあるマスは作りなおさない**（作りなおすと書いた字が消える。タイルを置くたびに `renderValues()` が走るため）。作りなおすのは表ごと作りなおす `renderAll()` のときだけで、そこは退避→復元でつながる
- 手書きは kurainohyou.html と同じ dataURL 退避方式（`saveInk` → 作り直し → `sizeCanvases` → `restoreInk`）。じどうは `counts` をそのまま出し、10以上は赤くして「まだくりあがっていない」ことを示す
- じどうのときだけ、各マスの右に ▲▼（`.spin`）を出す。押すとその位の数が ±1 され、タイルも増減する。数字は absolute の ▲▼ と重ならないよう、マスの中央のまま置いている
- **▲▼ での位の数は 0〜9**。9で▲は上へ繰り上がり、0で▼は上から繰り下がる。999＋1 や 1000−1 のように**何段も連鎖する**ので、`spinResult()` で結果を先に作り、作れないとき（上の位が表に無い／上が全部0）だけ null を返してボタンを disabled にする
  - 手で置いたタイルは10以上になれる（それが囲い＝繰り上がりの学習部分）。▲▼ だけが 0〜9 に正規化する道具
- リセットはタイル・手書き・くらいの範囲・表示モードの全部を初期値にもどす
