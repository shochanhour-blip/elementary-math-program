# kurainohyou.html の設計メモ
- たしざんモード：行Aと行Bに分割、タイルをドラッグで配置
- ひきざんモード：ONの間はタイルをタップすると斜線（removed状態）。専用の「ひく」ボタンはない
- タイルのplaceValue: 1000 / 100 / 10 / 1 / 0.1 / 0.01
- くりあがりゾーン：10枚そろったら上の位に繰り上げ確定
- 確認モーダルは `pendingAction` に何をするかを入れて「はい」で実行する。`pendingAction` を作るとき、ドラッグの payload（`type:'tile'`）を**後ろに展開すると `type` が上書きされて実行されない**（りょうがえが効かない不具合の原因だった）
- タイルの並びは**1列5個まで**（10個なら5×2列）。`autoScaleTileAreas()` が `.tile-area` の高さを「タイル5個ぶん＋上下padding」にして折り返しを起こす。
  - `box-sizing: border-box` なので、指定する高さに padding を入れ忘れると4個で折り返してしまう
  - 5行ぶんの縦、または列を並べた横がセルからはみ出すときは、タイルを `zoom` で縮める
  - 余裕は +2px だけ。増やすと6個めが入ってしまう
- state.tiles に全タイル管理、renderAll() で全体再描画
